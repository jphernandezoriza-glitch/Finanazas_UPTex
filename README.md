# Finanzas starter

Lienzo sanitizado para desarrollar `Modules/Finanzas`. Instala con `composer install`, `pnpm install`, copia `.env.example` a `.env`, configura SQLite, ejecuta `php artisan key:generate`, `php artisan migrate --seed` y `pnpm run build`.

Credenciales ficticias: `admin@uptex-sandbox.test` y `alumno@uptex-sandbox.test`; contraseña `Sandbox2026!`.

No contiene datos, archivos, pagos ni servicios institucionales. Al integrar, sustituye los placeholders por los servicios reales de alumno, archivo digital, adeudos, regularizaciones, auditoría y notificaciones.
